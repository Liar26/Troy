# TROY: notes for Claude Code

Minimal gallery of public-domain paintings from the Met, the Art Institute of Chicago and the Cleveland Museum of Art (open-access APIs; ids are offset per museum: AIC +10,000,000, CMA +20,000,000). Zero npm dependencies, vanilla frontend, no build step.

- Run: `npm run import` then `npm start` (port 3000). Offline test: `npm run mock` (see README).
- Backend: `server.js`, `lib/db.js` (JSON file), `lib/met.js`, `lib/aic.js`, `lib/cma.js`, `lib/world.js` (nationality + region labels), `lib/http.js` (polite client), `scripts/import.js` (`--sources met,aic,cma --target N`). AIC/CMA field shapes were written from their docs and tested only against test/mock-met.js: check the first real import's log.
- Frontend: `public/index.html`, `styles.css` (base), `art.css` (quiet skin), `art.js` (background art), `app.js` (History-API router, modal at `/painting/:id`).
- Rules: use ONLY the museum's own text about paintings (never generate art history). Hot-link images, never store them. Keep >= 100 ms between Met requests. The old `/v1/search` returns 410; use `/v1.1/search`.
- Look: quiet UI over 10 generative backgrounds (ink wash, contours, point cloud, flow lines, painting glow, ridgelines, constellation, halftone, watercolour, moiré rings). Default is "Surprise me": a different one on every visit/refresh, never the same twice in a row (localStorage `troy.art2` = 'shuffle' or a locked design, `troy.art.last`). The Art button steps through Surprise, each design, Plain. Colours in `public/art.css`, art in `public/art.js`. Dark default + light toggle.
- Share sheet (app.js openShare, [data-share]) and Feedback (/feedback, POST /api/feedback; env TROY_WEB3FORMS_KEY, TROY_FEEDBACK_WEBHOOK) exist; OG tags are injected in servePage.
- NEVER delete public/google1e0df8abfc805c5d.html (Google Search Console ownership proof; Google rechecks it).
- GoatCounter (troy.goatcounter.com) is the only third-party script; if the site code changes, update the CSP in server.js and the Privacy page together.
- NEVER remove the Pinterest p:domain_verify meta tag in public/index.html (Pinterest rechecks it).
- Keep it simple to modify. After each change, add a short entry to `BUILD_LOG.md`.
- Built: Privacy/Terms/Contact pages, TROY_EMAIL, data/hidden.json takedown list, CSP + security headers + rate limits in server.js (keep inline scripts out of index.html except the theme one; its hash is computed automatically), Masters (lib/famous.js: search every museum by artist, "Masters only" filter, artists page lists them first), Wikimedia source (lib/wiki.js: famous paintings held elsewhere, from Wikidata + Commons, ids +30,000,000; field shapes unverified live), search box that moves into the top bar on scroll (Explore), a new painting order and hero on every visit (Today stays daily), /img same-origin image route for the colour filter (only gallery images), Artists, Timeline, related paintings, next/previous (arrows, swipe), zoom, print/download, slideshow, sort, colour filter (read in-browser, cached in `troy.colors`), search suggestions, collections (`troy.cols`) with share links (`/c`) and export/import, sitemap.xml. Deliberately not built: accounts (privacy), see DEPLOY.md.
